Journal paper published in IEEE Transactions on Computational Biology and Bioinformatics

IEEE TCBB (Jan-Feb 2026) Vol. 23, No. 1, pp. 65-74 · PMID: 41247898

ASAP-ML: Antibiotic Susceptibility and Antibiogram Prediction With Machine Learning Methods

Doruk Topcu, Ebru Akcapinar Sezer
Abstract: Antimicrobial resistance (AMR) poses a global threat to public health. This study presents ASAP-ML, a comprehensive machine learning framework evaluating 10 classification algorithms across multi-source pathogen resistance datasets (ARDB, CARD, NCBI Pathogen Browser). The framework provides accurate predictions for antibiotic susceptibility patterns and automated antibiogram generation to accelerate clinical decision-making.
